Tap a date’s note field, then use the symbol toolbar to insert a Bullet Journal marker. The dates and weekdays are generated automatically. Today is highlighted in cyan when viewing the current month. The symbol toolbar scrolls horizontally if needed. Entries are saved automatically in this browser when storage is available. Export a backup regularly; Safari may clear local data, and downloaded file versions may not share storage.

Tap an entry to edit it, or Add entry to create another. Symbols insert into the selected entry. Entries save separately by date. This first daily log uses a fixed 5 mm row rhythm; long text wraps within its entry.

The page preserves A5 proportions and a 5 mm dot-grid rhythm. Test readability at your normal iPad viewing size, especially on the 31st.
